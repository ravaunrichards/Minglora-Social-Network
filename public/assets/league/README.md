# Original Minglora League artwork

`league-emblems.svg` is the original Minglora-owned vector asset sprite for League Arena. It contains the four Creator League division crests (A/B/C/D), four matching fragment crystals, first/second/third-place medals, top-ten/top-twenty recognition marks, and the four 2D Match Power-Up icons.

The sprite is designed for reuse in the responsive League Arena UI. It does not depend on generated profile data and it does not alter placement, ranking, fragments, shields, or match calculations.

The 20 JPEGs in the repository's `assets/League/` directory remain read-only reference captures. They are not copied into product artwork or served as live UI images; their interaction and layout guidance is implemented with Minglora-owned markup and assets.
