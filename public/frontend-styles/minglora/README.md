# Minglora visual style library

This directory contains the imported visual-style source collection adapted for Minglora. The styles are kept as individual assets for inspection and controlled, component-by-component use.

- Product name and all user-facing titles: **Minglora**
- The collection is not loaded globally. Minglora's own layout, navigation, profiles, Messenger, LIVE and MeetWave remain in control of the application.
- Compatible design tokens are applied through `/experience-center.css` to avoid collisions with Minglora components and responsive layouts.
- The source JavaScript files are retained as reference assets only; they are not loaded as application scripts.
- Saved appearance values retain their existing internal identifiers so member preferences are not reset by this naming update.

Available appearance presets include Default, Minimal, Flat, Swiss Modern, Editorial, Material Design, Fluent Design, Glassmorphism, Frosted Glass, Neo, Brutalist, Neumorphic, Claymorphism, Aurora, Cyberpunk, Memphis, Y2K, Pixel Art and Skeuomorphic.
