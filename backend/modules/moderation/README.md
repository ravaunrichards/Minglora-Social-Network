# Reports and moderation

**Current:** moderator-only account bans and explicit unbans are available in the private Admin Control Centre. A banned or suspended account is excluded from public profile serialization and lookup, discovery, feeds, search, relationship lists, Stories, group/page author displays, Messages, notifications and LIVE listings. Banned members cannot keep using an existing Minglora session. Unbanning restores the account to active visibility, but old sessions stay revoked and the member must sign in again.

The wider moderation workflow remains partial: report intake and review exist, while comprehensive evidence handling, triage automation, appeals, expiry and immutable audit coverage still need completion.

**Ownership:** report categories, triage queues, evidence references, moderator decisions, appeals, expiry and immutable audit records. Protect reporter/evidence privacy and enforce staff privileges on the server.
