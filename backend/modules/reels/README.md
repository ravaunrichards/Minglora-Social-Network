# Reels and short-form video

**Current:** Minglora has a video-only publishing composer, a dedicated full-screen vertical For You player and an existing Reels mode. The For You player supports swipe/scroll snapping, one-at-a-time autoplay, creator follow, likes, comments, saves, sharing, gifts, search, Not interested feedback and validated watch-time signals. Feed candidates are real member video uploads and respect audience visibility and block rules.

**Still pending:** server-side transcoding, adaptive bitrate renditions, generated thumbnails, richer caption tools and music-rights/licensing integrations. Playback events are measured from actual watch activity; never seed views or engagement.
