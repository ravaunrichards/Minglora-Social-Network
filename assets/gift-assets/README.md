# Minglora Gift Asset Production Workspace

Use this controlled workspace for original gift artwork, 3D models, audio masters and their provenance records. The canonical catalogue remains `data/minglora-gift-catalog.json`.

Keep source masters separate from approved production exports. Record author, source, licence, territory and modification/distribution permissions before promotion. Existing `assets/Gifts/` screenshot captures and `assets/Artwork/` extracted crops are read-only references until human review and rights clearance are recorded.
