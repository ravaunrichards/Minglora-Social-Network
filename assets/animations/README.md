# animations

Store reviewed original animation source, manifests and generated individual gift presentations.

Gift-capture extraction is isolated under `assets/animations/gifts/`. The extraction preserves the source screenshots in `assets/Gifts/`, produces one category-specific folder per recognized gift, and records matching catalog IDs and source crop coordinates in its manifest. The generated SVG motion is a presentation animation applied to a still capture; it is not a recovered source video or proprietary TikTok 3D animation.

Respect reduced-motion preferences, avoid flashing content, and do not animate fake engagement, viewer counts or notification activity.
