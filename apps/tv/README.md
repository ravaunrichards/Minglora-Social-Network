# TV application

**Status:** planned; no TV client exists yet.

Target: ten-foot interface with remote-control focus order, large type, safe-area layout, watch/feed browsing, live playback when available and QR/device-assisted authentication.

Acceptance: remote-only navigation, focus restoration, playback interruption/reconnect tests, readable contrast and device certification. TV views must not expose private messages to shared-screen viewers by default.
