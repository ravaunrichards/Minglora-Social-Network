# Feature implementation status

This document distinguishes working code from unfinished product requirements. An empty collection is a valid state; it must be shown as an honest empty state, never filled with fabricated records. See [the Facebook feature-parity audit](FACEBOOK_PARITY_AUDIT.md) for the full comparison and prioritized gap tracker.

## Empty-state rules

- A new account sees an empty feed until real posts exist. Posts and Stories accept uploaded media references only; pasted image URLs are rejected.
- No user cards or counts are fabricated to fill empty panels.
- Groups appear only after a real account creates them.
- Conversation lists appear only after real messages exist.
- Stories are shown only from real stored records.
- Marketplace and Jobs are retired in the current runtime; old migrations are historical and do not make them available. Do not claim either feature is live or seed sample listings, candidates, applications, prices or sales.
- Any future test fixture must use a temporary test database and be removed when the test finishes.
