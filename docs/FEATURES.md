# Feature checklist

| Area | Current implementation | Notes |
|---|---|---|
| Authentication | Registration, login, logout, hashed passwords, signed HTTP-only session cookie | Email verification and password reset are not yet implemented |
| Feed | Chronological feed, post composer, HTTPS image URL attachment, recent/oldest sort | File upload and feed ranking are not implemented |
| Reactions | Like toggle plus API support for love/care/haha/wow/sad/angry | UI currently exposes Like toggle |
| Comments | Add comments; latest three visible on feed cards | Edit/delete and moderation are future work |
| Profiles | View profile and posts; edit name, bio, location, avatar URL, cover URL | Privacy settings and profile visibility controls are future work |
| Friends | Send requests, accept incoming requests, see accepted friends | Unfriend/block/report are future work |
| Groups | Browse, create and join groups | Group posts, roles, events, and moderation are future work |
| Messages | Direct text messages and conversations | Real-time delivery, attachments, read receipts and message deletion are future work |
| Notifications | Social action notifications and mark-all-read | Push/email notifications are future work |
| Search | Search users, post text, group names and descriptions | Search index/ranking are not implemented |
| Responsive UI | Desktop three-column layout, compact tablet, mobile bottom navigation | Validate against your target devices before public launch |
