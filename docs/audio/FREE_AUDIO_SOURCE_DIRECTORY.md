# Minglora Free Audio Resource Directory

## Purpose and acceptance boundary

This is a discovery index for the source websites supplied for Minglora. Listing a website here does **not** certify that every file on that website is free, authentic, commercially usable, redistributable, or available for download. Rights are asset-specific and may vary by creator, licence, territory, subscription, and intended use.

Before an external recording enters the official platform library, preserve its exact original download page, original filename, website, file format, factual recording description, exact licence and licence URL, attribution text, explicit commercial-use permission, explicit redistribution/platform-delivery permission, download date, and SHA-256 checksum. Confirm that the binary was actually downloaded and tested. Never treat a homepage link or "free" label as a licence.

No files are installed or approved by this directory alone.

## Required Minglora audio types

- Real telephone and incoming video-call ringtones.
- Real notification, messaging, Messenger, delivery and error recordings.
- Real human speech, voice notes, reactions, laughter, cheering and applause.
- Real animals and wildlife.
- Real vehicles, engines and mechanical recordings.
- Real musical and cultural instruments.
- Real environmental, weather, household and everyday recordings.
- Real footsteps, movement, celebrations and party recordings.
- Real gift and interface-feedback recordings.
- Authentic Jamaican and wider Caribbean cultural recordings, with cultural context and creator attribution preserved.

## Per-file import checklist

- [ ] The exact binary file exists in the protected Minglora Storage bucket.
- [ ] Original filename and source download page are recorded.
- [ ] The source website and original creator are identified where available.
- [ ] File format and audio technical metadata are inspected.
- [ ] The factual description matches what the recording actually contains.
- [ ] The exact licence and licence URL are retained.
- [ ] Commercial-use permission is explicitly verified.
- [ ] Redistribution and platform-delivery permission is explicitly verified.
- [ ] Attribution requirements are preserved and satisfied.
- [ ] Download date and SHA-256 checksum are recorded.
- [ ] The audio was listened to and confirmed as a real recording.
- [ ] Duplicate, corruption, safety and privacy checks pass.
- [ ] Authorized reviewers approve authenticity and licence status before assignment.

## Strict exclusions

Do not approve AI-generated voices, robotic voices, synthetic tones, oscillator sounds, generated or procedural effects, or fake recordings described as authentic. Do not bypass site restrictions, DRM, authentication, or paid access. If the licence does not clearly allow commercial use and redistribution by Minglora, do not assign the file as an official platform sound.
